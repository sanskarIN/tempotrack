# Privacy

TempoTrack is designed to work without an account or hosted backend.

## Data stored locally

The app can store:

- saved stopwatch sessions and lap data;
- app preferences;
- a temporary active-stopwatch checkpoint;
- files created by explicit export actions.

## Data transmission

The application code does not include analytics, advertising, telemetry, authentication, or cloud-sync services. TempoTrack does not automatically transmit session data.

If you export a CSV or JSON file and then move/share it using operating-system tools, that action is under your control and the destination's privacy terms apply.

## Android backup

Saved sessions and preferences are eligible for Android platform backup/device transfer. The transient active-stopwatch checkpoint and export directory are excluded from cloud backup.

## Deleting data

Saved sessions can be deleted in History. Application-private data can also be removed by clearing application data or uninstalling the app.
