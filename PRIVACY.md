# Privacy

TempoTrack is designed to work without an account or hosted backend.

## Data stored locally

The app can store:

- saved stopwatch sessions and lap data;
- app preferences;
- a temporary active-stopwatch checkpoint;
- files created by explicit export actions;
- temporary cache files created only when you explicitly choose a platform share action.

## Data transmission

The application code does not include analytics, advertising, telemetry, authentication, or cloud-sync services. TempoTrack does not automatically transmit session data.

Export and share operations happen only after an explicit user action. Android sharing prepares a temporary app-cache file and delegates the destination choice to the operating-system share sheet using a read-only content URI grant. TempoTrack does not choose or contact a recipient itself. Once you choose another app or service, that destination's privacy terms apply.

## Android backup

Saved sessions and preferences are eligible for Android platform backup/device transfer. The transient active-stopwatch checkpoint, generated export directory and temporary share-cache files are excluded from cloud backup.

## Deleting data

Saved sessions can be deleted in History. Application-private data can also be removed by clearing application data or uninstalling the app. Temporary share-cache data is stored in the application cache area and may be reclaimed by the operating system.
